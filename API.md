# CareerX API Specification

## Endpoint

`POST /api/simulate`

Simulates three tailored career paths for a college student based on their academic stage, existing skills, and interests.

---

## Headers

### Request Headers
- `Content-Type: application/json`

### Response Headers
- `Content-Type: application/json`
- `X-CareerX-Source: mock | ai | fallback`
  - `mock`: Response returned from `/lib/mock/simulate.json` (when `USE_MOCK=true`).
  - `ai`: Response generated by the Claude AI model and validated against the Zod schema.
  - `fallback`: Response served from `/lib/fallback/result.ts` when Claude calls fail or time out after retrying.

---

## Environment Variables

| Variable | Required | Default | Description |
|---|---|---|---|
| `ANTHROPIC_API_KEY` | Yes (for AI mode) | None | Anthropic API key. Server-side only; never logged or exposed to the client. |
| `USE_MOCK` | Optional | `true` | When set to `"true"`, bypasses Claude and serves validated mock results immediately. |
| `ANTHROPIC_MODEL` | Optional | `claude-sonnet-5-5` | The Anthropic model identifier used for simulation requests. |

---

## Request Body

```json
{
  "year": 1,
  "skills": ["Python", "C++", "HTML"],
  "interests": ["AI", "Web Development"],
  "strengths": ["Problem Solving", "Mathematical Reasoning"]
}
```

### Request Fields & Validation Rules

- `year` (`number`, **required**): Integer from `1` to `4` (`1 | 2 | 3 | 4`).
- `skills` (`string[]`, **required**): Array of skills.
  - Non-empty (at least 1 item).
  - Maximum 20 items.
  - Trimmed, empty strings stripped.
  - Deduplicated case-insensitively.
  - Maximum 50 characters per item.
- `interests` (`string[]`, **required**): Array of interests.
  - Non-empty (at least 1 item).
  - Maximum 20 items.
  - Trimmed, empty strings stripped.
  - Deduplicated case-insensitively.
  - Maximum 50 characters per item.
- `strengths` (`string[]`, *optional*): Array of self-reported strengths.
  - Maximum 20 items.
  - Trimmed, empty strings stripped.
  - Deduplicated case-insensitively.
  - Maximum 50 characters per item.

### Constraints Enforced on Response
- `paths`: Exactly 3 items.
- `fitScore`: Integer between `0` and `100`.
- `skillGaps`: 3–5 items per path.
  - `importance`: `"high" | "medium" | "low"`.
  - `currentLevel`: Integer `0`–`5`.
  - `targetLevel`: Integer `0`–`5`, must be $\ge$ `currentLevel`.
- `milestones`: 1–5 items per path.
- `projects`: Exactly 3 items, ordered easy to hard (`difficultyRank: beginner <= intermediate <= advanced`), `weeks` integer $\ge 1$.
- `first30Days`: Exactly 4 items for weeks `1`, `2`, `3`, `4` (once each), each with 3–4 concrete tasks.

## Error Responses

### Invalid Request (`400 Bad Request`)

Returned when the JSON payload is malformed or violates the `SimulationRequest` schema. Anthropic is never invoked for invalid requests.

```json
{
  "error": {
    "code": "INVALID_REQUEST",
    "message": "Validation failed for simulation request",
    "details": [
      "skills: Skills must contain at least 1 item",
      "year: Invalid input"
    ]
  }
}
```

### Method Not Allowed (`405 Method Not Allowed`)

Returned when non-POST HTTP methods (such as `GET`, `PUT`, `DELETE`) are called.

```json
{
  "error": {
    "code": "METHOD_NOT_ALLOWED",
    "message": "Only POST requests are supported"
  }
}
```

## Operating Modes & Reliability

1. **Mock Mode (`USE_MOCK=true`)**:
   - The route parses and validates the request.
   - Immediately returns the validated `/lib/mock/simulate.json` result.
   - Header: `X-CareerX-Source: mock`.

2. **AI Mode (`USE_MOCK=false`)**:
   - Validates the incoming request and normalizes strings.
   - Invokes Claude (`@anthropic-ai/sdk`) using the system and user prompt.
   - Attempts response extraction, safe numeric normalization, and Zod validation.
   - If Attempt 1 fails, automatically retries once with feedback on the failure if $\ge 12$ seconds remain within the 55-second deadline.
   - If Attempt 2 succeeds, returns the result with `X-CareerX-Source: ai`.

3. **Fallback Mode**:
   - If Claude fails twice, times out, or `ANTHROPIC_API_KEY` is not configured, the endpoint returns the hardcoded `/lib/fallback/result.ts` dataset.
   - HTTP Status: `200 OK`.
   - Header: `X-CareerX-Source: fallback`.
   - The frontend is guaranteed to receive a schema-compliant response.
